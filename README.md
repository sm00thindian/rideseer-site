# rideseer.com

The RideSeer website: a landing page, the user guide (`guide.html`) and the privacy policy (linked from the Play Store listing). Plain HTML and CSS, served by GitHub Pages at https://rideseer.com. The app itself lives in a separate private repo.

`guide.html` is generated from the app repo's `docs/user-guide.md` by `npm run site-guide` there: don't edit it by hand.

Keep `privacy.html` in step with what the app actually sends: the privacy table in the app repo's `docs/user-guide.md`.
